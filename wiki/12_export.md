## Overview of Outputs

Graphify can export the same graph in multiple formats for different use cases:

| Output | File | Use case |
|--------|------|---------|
| JSON | `graph.json` | GraphRAG, programmatic access, future --update runs |
| HTML | `graph.html` | Interactive browser visualisation |
| Obsidian vault | `obsidian/` | Note-taking, navigation, team knowledge base |
| Canvas | `obsidian/graph.canvas` | Obsidian's structured visual layout |
| SVG | `graph.svg` | Embed in GitHub README, Notion, documents |
| GraphML | `graph.graphml` | Gephi, yEd, professional graph tools |
| Cypher | `cypher.txt` | Neo4j import |
| MCP server | (live process) | Real-time agent access via stdio |

## to_json() — The Primary Output

```python
def to_json(G: nx.Graph, communities: dict[int, list[str]], path: str) -> None:
    from networkx.readwrite import json_graph
    data = json_graph.node_link_data(G)
    # Annotate each node with its community
    node_community = {n: cid for cid, nodes in communities.items() for n in nodes}
    for node in data["nodes"]:
        nid = node["id"]
        if nid in node_community:
            node["community"] = node_community[nid]
    Path(path).write_text(json.dumps(data, indent=2))
```

`json_graph.node_link_data(G)` converts the NetworkX graph to the standard node-link JSON format:

```json
{
  "directed": false,
  "multigraph": false,
  "graph": {},
  "nodes": [
    {"id": "client_httpclient", "label": "HTTPClient", ...}
  ],
  "links": [
    {"source": "client_httpclient", "target": "client_get", "relation": "method", ...}
  ]
}
```

Note: NetworkX uses `"links"` for edges in its serialisation format (not `"edges"`). This is why `build_from_json()` has the compatibility fix at the start.

The community ID is added to each node's JSON entry here. This is the only place where community membership is written into the permanent output — nodes don't have community IDs during extraction.

## to_html() — Interactive Visualisation

The HTML export uses **vis.js** (a JavaScript graph library) to render an interactive force-directed graph in the browser. No server needed — it's a single self-contained HTML file.

The function embeds:
1. The vis.js library (minified, inline)
2. The graph data as a JavaScript variable
3. Configuration for colours, physics, and interaction

Community colours are generated by assigning each community a distinct colour from a predefined palette. All nodes in the same community share a colour.

Size limit: `graph.html` is not generated for graphs with > 5,000 nodes (the browser would crash rendering it). The skill checks this before calling `to_html()`.

## to_obsidian() — Obsidian Vault

This is the richest export. It generates a folder that Obsidian (a note-taking app) can open as a "vault" — a connected web of markdown notes with backlinks and graph view.

```
obsidian/
├── _COMMUNITY_Attention_Mechanism.md   # one overview note per community
├── _COMMUNITY_Training_Pipeline.md
├── client_py.md                        # one note per node
├── models_py.md
├── transformer.md
├── ...
└── graph.canvas                        # structured visual layout
```

**Community notes (`_COMMUNITY_*.md`)** — overview articles with:
- List of all nodes in the community
- Cross-links to other communities
- Cohesion score
- Dataview query (if Dataview plugin is installed, auto-generates a table of all nodes)

**Node notes** — one per node with:
- Node metadata (source file, line number, type)
- All edges listed as `[[wikilinks]]` so Obsidian builds a backlink graph
- Community membership

**graph.canvas** — Obsidian's Canvas format. Groups nodes into visual boxes by community. Unlike the force-directed HTML graph, this is a static structured layout with explicit positioning.

## to_canvas() — Obsidian Canvas Format

Obsidian Canvas is a JSON format for infinite-canvas diagrams. Graphify generates:
- One "group" rectangle per community, positioned in a grid
- One "node" card per graph node, positioned inside its community group
- "Edge" connections between nodes

This gives you a structured overview where communities are visually separated — much easier to read than a force-directed graph where everything is tangled.

## to_cypher() — Neo4j Import

Generates a Cypher script for Neo4j:

```cypher
MERGE (n:Node {id: 'client_httpclient'})
SET n.label = 'HTTPClient', n.source_file = 'src/client.py', n.community = 2;

MERGE (a:Node {id: 'client_httpclient'})
MERGE (b:Node {id: 'client_get'})
MERGE (a)-[:method {confidence: 'EXTRACTED', weight: 1.0}]->(b);
```

`MERGE` is used instead of `CREATE` so the script is **idempotent** — you can run it multiple times without creating duplicates. Running it again after `--update` just updates existing nodes.

## push_to_neo4j() — Live Neo4j Push

Instead of generating a file, this function connects directly to a running Neo4j instance:

```python
def push_to_neo4j(G, uri, user, password, communities):
    from neo4j import GraphDatabase
    driver = GraphDatabase.driver(uri, auth=(user, password))
    with driver.session() as session:
        for node_id, data in G.nodes(data=True):
            session.run(
                "MERGE (n:Node {id: $id}) SET n += $props",
                id=node_id, props={...}
            )
        for u, v, data in G.edges(data=True):
            session.run(
                "MATCH (a:Node {id: $src}), (b:Node {id: $tgt}) "
                "MERGE (a)-[r:RELATION {relation: $rel}]->(b) SET r += $props",
                src=u, tgt=v, ...
            )
```

Uses `neo4j` Python driver. The `MERGE ... SET` pattern updates existing nodes/edges without creating duplicates.

## to_svg() — Scalable Vector Graphics

Generates a static SVG of the graph using NetworkX's `draw()` function with matplotlib. Nodes are coloured by community.

SVG embeds in:
- GitHub README (native rendering)
- Notion pages (inline embed)
- Obsidian notes (renders in preview mode)
- Any modern browser

Limitation: static — you can't click nodes. Use HTML for interactivity.

## to_graphml() — GraphML for Professional Tools

GraphML is an XML-based graph format supported by:
- **Gephi** — professional graph visualisation and analysis
- **yEd** — diagram editor
- **Cytoscape** — bioinformatics graph tool
- Any tool that says "import GraphML"

```python
def to_graphml(G, communities, path):
    # Add community as a node attribute
    for cid, nodes in communities.items():
        for n in nodes:
            G.nodes[n]["community"] = cid
    nx.write_graphml(G, path)
```

`nx.write_graphml()` is NetworkX's built-in GraphML exporter.

## sanitize_label() — Security in Exports

Before any user-supplied text (node labels, community names) is written to outputs, it passes through `security.sanitize_label()`:

```python
def sanitize_label(label: str, max_length: int = 200) -> str:
    label = label[:max_length]
    label = label.replace("<", "&lt;").replace(">", "&gt;")
    label = label.replace('"', "&quot;").replace("'", "&#39;")
    label = re.sub(r"[\x00-\x08\x0b-\x0c\x0e-\x1f\x7f]", "", label)
    return label
```

HTML-escapes `<`, `>`, `"`, `'` and strips control characters. This prevents XSS if node labels end up in HTML output (e.g. a label that says `<script>alert(1)</script>`).
